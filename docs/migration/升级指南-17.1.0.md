# 17.0.x → 17.1.0 迁移说明

## 坐标变化

| 旧 | 新 |
|---|---|
| 父工程 `qof-spring-boot-starter` (pom) | `qof-parent` |
| 业务引入 `qof-core` | 推荐改为 `qof-spring-boot-starter`（仍可继续用 `qof-core`） |
| 演示 `qof-starter` | `qof-examples`（禁止业务依赖） |

版本号：`17.1.0`

## 行为变化

1. **内置 `/file` Controller 默认关闭**  
   需要时配置：
   ```yaml
   qof:
     web:
       enabled: true
       expose-advice: true
       base-path: /file
   ```

2. **全局异常不再污染宿主**  
   Advice 仅处理 `io.github.codeyunze.controller`；且默认不注册。

3. **客户端工厂**  
   按 `ObjectStorageProvider#mode()` 匹配；自定义存储请实现该 SPI。

## mall 等存量项目

- 依赖 `qof-core` / `qof-web` 坐标可保留，版本升至 `17.1.0`
- 若使用自建 Controller（如 `/sys/file`），一般**不必**打开 `qof.web.enabled`
- 父 BOM 若曾引用旧 parent artifact，改为 `qof-parent` 或继续只管理 `qof.version` 属性
